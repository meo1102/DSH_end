# TaskFlow 项目约定

## 这是什么

一个零依赖的 Node.js 命令行任务管理工具，用来演示“从零到一个可验收的小软件”的完整流程。它是教学示例，不是生产工具。

## 命令

- 跑测试：`node --test --test-isolation=none "test/*.test.js"`
- 跑命令：`node bin/taskflow.js <命令>`
- 看用法：`node bin/taskflow.js help`

## 约束

- 只用 Node 内置模块（`node:fs/promises`、`node:path`、`node:test`、`node:assert`），不新增第三方依赖。
- 不发起网络请求，不读写项目目录以外的文件（测试用系统临时目录除外）。
- 数据写入必须原子：先写临时文件，再 `rename` 覆盖。
- 错误分两类：用法错误退出码 `2`，业务失败退出码 `1`，成功 `0`。新增错误路径时遵守这个约定。
- 新增行为先写测试；改完必须跑全量测试。
- 注释和文档用简体中文，标识符用英文；单个函数尽量控制在 40 行以内。

## 交付标准

- 19 个以上测试全部通过，0 失败。
- README 里的“快速开始”命令可以原样照抄执行。
- 破坏 JSON 文件时给出明确报错，而不是抛栈。
