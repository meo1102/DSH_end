## 1. 方向

让人类不必盯着 agent。插件只在两个时刻提醒：**任务结束**、**轮次需要人类授权/确认**。
提醒必须可信、可读、可定制、可关闭；**只告知，不代替人做任何决定**。

## 2. 目标（可观察、可验收）

| # | 目标 | 可观察判据 | 不成立（反例） |
|---|---|---|---|
| **G1** | 完成提示 | `running → idle` 后 P95 ≤500 ms 出现；区分完成/失败/中断/停止/被阻止；用户主动取消不提示；页面不可见或被遮挡时发系统通知 | 误报、漏报、Stop 被标完成、重复弹 |
| **G2** | 授权/确认提醒 | 执行中等待人类授权或确认时，每个等待 episode 提醒一次；解决后清除；点击只打开会话 | 替人批准/拒绝、读正文、重复轰炸、无可靠信号仍硬猜 |
| **G3** | 弹窗样式自定义 | 位置（四角）、明暗（跟随/亮/暗）、尺寸（紧凑/标准）、停留时长、标题开关可配；纯 DSH token、无任意 CSS | 布局溢出、主题错乱、需要构建链或第三方库 |

**G2 前置**：先在真实宿主取证「等待授权/确认」的可观察信号；取证不成立则记为「未实现」，不得用启发式冒充。
**G3 首版**只走宿主 `Config` / `cordis.patch.yml`；设置面板、任意 CSS 需另行过门禁。

## 3. 边界（非目标）

- **只告知**：不批准/拒绝/确认/回复，不点击工具，不改会话状态，不向 agent 注入任何消息或信号；点击通知只做「打开会话」这一用户主动导航。
- **只读最小元数据**：显示名、会话 id、状态、outcome 枚举、时间；不读消息正文、工具参数、文件内容、模型输出、密钥。
- **零复杂依赖**：无第三方运行时依赖、无构建链、无 CSS 框架/图标字体；仅 Node 内置 + DSH/Cordis/React 宿主能力；测试用 `node:test`。
- **不碰宿主**：不修改 DSH 源码/安装目录；不跨工作区、不联网外发、不做遥测、不写 localStorage/IndexedDB/cookie。
- **不做**：任务管理、通知历史中心、托盘/声音、移动端、自动重试/调度、对外发布承诺、应用退出后的通知。

## 4. 风险分级

| 级别 | 定义 | 例子 | 默认动作 |
|---|---|---|---|
| **R0** | 纯展示、可逆、无数据 | 样式偏差、动画、重复浮层 | 直接修，台账一行 |
| **R1** | 提示质量受损、仍可逆 | 漏一条完成提示、文案错、延迟 >1 s | 本地 S3，阶段内修；同阶段复发 ≥2 次升 S2 |
| **R2** | 可能误导人类判断/授权 | 授权提醒误报/漏报、映射错会话、Stop 标成完成 | S2：1 个工作日内报告；未修复前暂停该能力 |
| **R3** | 越界/不可逆/隐私/代替操作 | 读正文、代替授权、外发数据、改宿主 | S1：立即停，1 h 内知会，24 h 内人裁 |

## 5. 项目停止条件

满足任一条即停，不得用「再试一次」绕过：

1. 触发任一红线（§6）→ 全停、冻结、事故记录。
2. G2 的等待信号在本阶段内无法在真实宿主取证 → 取消 G2，保留 G1/G3，不猜。
3. 需要新增运行时依赖、构建链、联网或改 DSH 源码 → 停，交人类决定；默认拒绝。
4. 自动化基线跌破 142/142，或真机核心项回归且阶段内无人修复 → 暂停新功能。
5. 连续两道门禁失败，或阶段预算耗尽（2 周 / 20 个有效 agent 回合，先到为准）→ 停，复审并重写宪章。
6. 人类常规事务时间连续两周 >2 h/周 → 缩范围、降并发，不加控制。
7. 无具名人类所有者/验收人 → 只做 R0/R1，不发布、不声称可用。
8. 宿主 API 不兼容且无受支持扩展点 → 冻结最后可用版本，转维护模式，不 patch 源码。
9. 真实安装/验收环境无法恢复 → 停止真机声明，只交付代码 + 未验证清单。

## 6. 红线

1. **不代替人类决定**：不批准/拒绝/确认/回复，不自动点击，不注入消息或信号。
2. **不读、不传、不落盘会话内容**：正文、工具参数、文件内容、密钥一律不碰；只允许 §3 的元数据。
3. **不引复杂依赖**：无第三方运行时依赖、无构建链；不修改 DSH 源码/安装目录；不联网外发。
4. **不静默失败、不伪造证据**：未验证就写未验证；验收必须列失败/未测项；禁止「全绿」话术。
5. **不跨工作区/用户泄漏**：无遥测、无 localStorage/IndexedDB/cookie、无通知历史持久化。
6. **不骚扰**：默认频率上限、每个等待 episode 只提醒一次、可关闭；不做恐吓/诱导/无限提醒。
7. **不破坏宿主**：异常全捕获；插件崩溃不得影响会话执行；禁用/卸载零残留。
8. **不越权改基线**：宪章/红线/停止条件只能由人类所有者改；agent 只能提案，版本化留痕。

## 7. 升级触发与基线冻结

- **S1（立即）**：红线、R3、隐私/数据事故、宿主崩溃、错误授权风险 → 停止 + 立即通知人类。
- **S2（1 个工作日内）**：R2、授权提醒漏报/误报、验收声明失效、安装损坏、与其他插件冲突。
- **S3/S4（本地）**：R1/R0、样式与文案问题 → 台账一行，人类每周抽样 1–2 条。
- **阶段结束 = 升级触发**：冻结基线（git commit/tag + 源码/测试哈希 + 自动化日志 + 验收基线 A 版本 + 能力基线 C 版本），出一页《阶段报告 + 门禁检查单》，提交人类所有者，并作为**进化提案**交给 agent 集群。集群可学习，但不得自行改写宪章、基线或验收结论；下一阶段只在门禁决定「继续/收缩/停止」后开始。

## 8. 真实项目取证与变更权

- 本项目是 PLAN-v0.7 / REPORT-v4 的**真实项目取证案例**：一页宪章、一本台账（[`ledger.md`](../../ledger.md)）、每阶段一页门禁检查单（[阶段 0 示例](../../gates/2026-11-04-stage-0.md)）、一份含负事实的验收报告。
- 事实写「陈述/来源/方法/时间/状态/核验人」；**模型输出默认是主张**；高影响事实由非作者核验；主张与事实分列；过期事实不得用于门禁。
- 人类注意力预算：常规事务 ≤2 h/周；S1/S2 另计；每周抽样 1–2 条 S3/S4；超预算先缩范围，不加控制。
- 变更权：方向/红线/停止条件/宪章批准归人类所有者；实现路线与 S3/S4 裁决归集群管家；本文件改动需版本号 + 理由 + 影响 + 人类批准，历史不删改。
