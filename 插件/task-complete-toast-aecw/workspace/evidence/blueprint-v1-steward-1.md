## 1. 本阶段目标

- 对应宪章目的：让提醒“可信、可读、可定制、可关闭”，且不遮挡人类操作。
- 本阶段可观察结果：
  1. AECW 三域结构生效，`STATUS.md` 是唯一当前状态，`ledger.md`/证据/门禁可追溯；
  2. G2-8、G3-4b 有真机结论（通过或由人类重新书面接受）；
  3. 13 项历史 V 项逐项有裁决（做/接受/删除），V01/V04/V23 有处置；
  4. 真机证据至少补齐关键截图/录屏，或显式登记证据缺口；
  5. 一次“新 agent 只读 STATUS + 证据”的接手复测达到约定目标。
- 本阶段非目标：不新增功能、不改 `Config` 契约、不做配置面板、不接外部发布。

## 3. 接口与契约

| 接口 | 谁提供 | 谁消费 | 契约（输入/输出/错误） | 兼容策略 |
|---|---|---|---|---|
| 宿主事件 → 结果桥 | DSH `api-session/status` + `turn/end` | 插件宿主半区 | `running:true→false` + outcome；未知结果回落 `completed` | 只读；失败不阻塞提示 |
| 宿主路由 | 插件宿主半区 | 客户端 | `GET /dsh-task-complete/outcome?sessionId=` → 200/400/404/405 | 非 2xx 降级 `completed` |
| 授权/确认快照 | `uiSession.sessionStatus.pendingInteraction` | 客户端 | 只读 `key/kind`；无 `agent` 映射则跳过 | kind 新增需显式适配；不读内容 |
| 外观配置 | 宿主 `Config.appearance` | 客户端 | 扁平投影五字段；越界回落默认 | 改配置需重启宿主 |
| 安装/加载 | DSH profile bundle + junction | 宿主 | entry active；`shell.overlay` order 100 | 目录搬动后必须重装；以运行态探针为准 |

## 6. 阶段验收

- 聚合判据：WP-1 完成（freeze + start 有据）；WP-2/WP-3 有真机结论；WP-4 每项有裁决；WP-5 有截图或缺口登记；WP-6 达到约定阈值。

- 允许的遗留：仅限人类在 `human/acceptance.md` 书面接受的项；未接受项不得写成通过。
- 阶段结束必须停、更新 `STATUS.md`、出门禁一页、等下一道门。
