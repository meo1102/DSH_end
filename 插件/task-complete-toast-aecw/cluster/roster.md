## 边界

- 人类不替集群写代码/测试；集群不替人类批准蓝图、裁决 S1/S2、接受遗留或下开工令。
- 高影响验收至少一次“非作者”检查（人类真机 / 另一个 agent / 独立工具）；同作者验证只能写“可复现”，不能写“独立通过”。
- 需要独立调查时临时指定验证者，不设常设“异议守护者”。
- 多 agent 是可选放大，不是本阶段前提；没有上下文隔离的多 agent 只会放大分叉。
