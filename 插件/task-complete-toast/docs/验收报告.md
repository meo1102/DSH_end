## 4. 真机缺陷与修复

| 缺陷 | 根因 | 修复 |
|---|---|---|
| V13 遮挡无通知 | 通知 `tag` 复用导致 Windows 静默更新 | ADR-014 唯一 tag（`hash16`，25 字符） |
| V21 双标签双弹 | 判定早于认领窗结束，pending 即胜出 | ADR-015 等待窗口结束再判定 |
| V12 Stop 仍提示完成 | 结果无新鲜度 + 注入包装丢 `since` 参数 | ADR-016 按 `since` 过滤 + 重试；补三参转发 |
| V03 工区名回落 | 快照形状是 `{items}`，实现只认 `byId` | 认 `items`；会话名取 `displayTitle` |
| 编码事故 | PowerShell 默认编码改写 UTF-8 | 由恢复副本重建，0 个 `U+FFFD`；规则写入交接 |
