# 真机验收清单 · G1/G2/G3

> 目的：把 `门禁-阶段1/2` 的「真机未验」逐项变成可执行步骤。每项只需观察并记录，不改代码。
> 前提：`include:task-complete-toast` 为 active；**先刷新页面**（G2/G3 客户端代码才会加载）。

## 0. 前置检查

1. 插件页/`plugin_manager` 看 `include:task-complete-toast` 为 `active`。
2. 刷新页面（`Ctrl+R`）。
3. 若刚改过 `appearance`：**重启应用**（宿主 Config 改动不走页面刷新）。
4. 若插件静默消失：查 profile junction 是否指向本目录（见交接说明 §5 第 9 条）。

## 1. G1 完成提示

| # | 操作 | 预期 | 记录 |
|---|---|---|---|
| G1-1 | 让任一 Agent 完成一轮普通任务 | 右下角出现「任务完成」两行卡片 | 通过/失败 |
| G1-2 | 不操作，等待 | 约 5 s 自动消失 | 通过/失败 |
| G1-3 | 出现后鼠标移入，等 6 s，再移出 | 移入期间不消失；移出后重新完整计时 | 通过/失败 |
| G1-4 | 把窗口最小化/被遮挡后完成一轮 | Windows 通知中心出现通知 | 通过/失败 |
| G1-5 | 点击应用内卡片 | 打开对应会话并关闭卡片 | 通过/失败 |

## 2. G2 授权/确认提醒

触发方式（任选，**不要用破坏性操作**）：

- 在会话里让 Agent 调用 `ask_user_question` 问一个无害问题；
- 或让 Agent 执行一个需要审批的无害命令（例如写系统临时目录），测试后拒绝。

| # | 操作 | 预期 | 记录 |
|---|---|---|---|
| G2-1 | 在**别的会话**触发等待授权/回答 | 出现提醒卡：需要授权/需要回答 + 工作区[会话] · 等待状态；**不应遮挡**目标会话操作（未进入前可能显示） | 通过/失败 |
| G2-2 | 等 10 s 不操作 | 卡片仍在（不做定时自动消失） | 通过/失败 |
| G2-3 | 进入目标会话 | 卡片收起；系统通知同时关闭；授权/回答按钮可点击 | 通过/失败 |
| G2-4 | 在**目标会话内**触发等待 | 不出现提醒卡、不发系统通知 | 通过/失败 |
| G2-5 | 回答/批准/拒绝 | 卡片消失；系统通知同时关闭 | 通过/失败 |
| G2-6 | 再触发一次，点卡片 X | 卡片消失；本轮等待内不再补弹 | 通过/失败 |
| G2-7 | 窗口隐藏时触发 | 收到系统通知；进入会话/处理后通知关闭 | 通过/失败 |
| G2-8 | 两个会话同时等待 | 最多 3 条提醒，按出现顺序 | 通过/失败 |

**不通过时先查**：页面是否刷新；`uiSession` 是否变化（`pendingInteraction` 字段）；浏览器控制台是否有插件报错。

## 3. G3 外观配置

在 `%USERPROFILE%\.dsh\profiles\desktop\cordis.patch.yml` 追加/合并（先备份）：

```yaml
- id: task-complete-toast
  name: '@local/task-complete-toast'
  config:
    appearance:
      position: top-left
      theme: dark
      size: compact
      durationMs: 8000
      showTitle: false
```

改完**重启应用**，再刷新页面，触发一次完成提示，逐项目视：

| # | 配置 | 预期 | 记录 |
|---|---|---|---|
| G3-1 | 四角各 1 次 | 卡片贴对应角，距边 24 px，不溢出 | 通过/失败 |
| G3-2 | `theme: light` / `dark` / `system` | light 白底深字；dark 深底浅字；system 跟随应用 | 通过/失败 |
| G3-3 | `size: compact` / `standard` | compact 300 px/小字号；standard 360 px | 通过/失败 |
| G3-4 | `durationMs: 2000` / `15000` | 分别约 2 s / 15 s 消失；G2 常驻提醒不变 | 通过/失败 |
| G3-5 | `showTitle: false` | 完成卡只留明细行；G2 提醒仍有标题 | 通过/失败 |
| G3-6 | 窄窗（约 360 px） | 卡片不裁切、不溢出 | 通过/失败 |
