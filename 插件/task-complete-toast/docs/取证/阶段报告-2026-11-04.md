## 4. 关键学习（给 agent 集群）

1. **文档声明 ≠ 运行事实**：README/交接称“已安装启用”，实际 junction 指向旧路径且 bundle 缺失；接管必须先做运行态取证。
2. **G2 不要进 waterfall**：`uiSession.sessionStatus` 已提供每个会话的 `pendingInteraction.key/kind`，只读投影即可；监听 approval/user-question waterfall 会进入决策路径且有顺序风险。
3. **G3 主题要作用域化**：显式 light/dark 用 DSH static token + 容器 `data-theme`，不调用全局 `setTheme`、不写死颜色。
4. **常驻浮层必须避让输入区**：只约定 click-through 不够；右下角常驻卡片会盖住授权/回答按钮，必须独立落点或安全区。
5. **阶段门禁必须带负事实**：未验项、多标签、开关缺失都写进门禁，避免“全绿”叙事。
